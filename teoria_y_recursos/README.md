# 📚 Teoría, Apuntes y Recursos de Referencia

> Espacio de almacenamiento y consulta de materiales teóricos, resúmenes de clase para **Algoritmos y Estructuras de Datos (CC232 - UNI)**, enlaces a herramientas interactivas y bibliografía canónica.

---

## 🎯 Propósito del Directorio

Este directorio actúa como la **Capa 1 (Fuentes en Bruto)** para todo el contenido teórico que fundamenta las implementaciones de código y las fichas de conocimiento compiladas en el [[index|Segundo Cerebro (`wiki/`)]].

Aquí se recopilan:

1. **Apuntes de Clase:** Notas y resúmenes de las clases teóricas del profesor Lara (UNI).
2. **Cheat Sheets & Formularios:** Tablas de referencia rápida sobre propiedades asintóticas, límites de tiempo de CPU y relaciones de recurrencia.
3. **Bibliografía y Lecturas:** Guías de lectura de los libros clásicos de computación.
4. **Visualizadores Interactivos:** Enlaces y apuntes sobre herramientas visuales para comprender el flujo de los algoritmos.

---

## 📖 Bibliografía de Referencia Recomendada

| Libro                                 | Autores                          | Enfoque Principal                                                                     |
| :------------------------------------ | :------------------------------- | :------------------------------------------------------------------------------------ |
| **Introduction to Algorithms (CLRS)** | Cormen, Leiserson, Rivest, Stein | Rigor matemático, demostraciones formales, análisis asintótico y pseudocódigo.        |
| **Algorithms (4th Edition)**          | Robert Sedgewick, Kevin Wayne    | Enfoque práctico, análisis empírico y visual de estructuras y algoritmos.             |
| **Competitive Programming 4**         | Steven Halim, Felix Halim        | Técnicas de optimización, trucos de C++, Two Pointers, Grafos y DP para competencias. |
| **Clean Code**                        | Robert C. Martin                 | Nombres expresivos, funciones pequeñas, legibilidad y modularidad.                    |

## 🌐 Recursos y Visualizadores Interactivos

Para entender en profundidad cómo mutan las estructuras en memoria y cómo se ejecutan los pasos algorítmicos:

- [VisuAlgo.net](https://visualgo.net/): Visualización interactiva de estructuras de datos (Árboles, Grafos, Heaps, Tablas Hash).
- [CSVisTool](https://csvistool.com/): Animación paso a paso de algoritmos clásicos.
- [USFCA CS Visualizations](https://www.cs.usfca.edu/~galles/visualization/Algorithms.html): Animaciones canónicas de árboles AVL, B-Trees y Red-Black Trees.
