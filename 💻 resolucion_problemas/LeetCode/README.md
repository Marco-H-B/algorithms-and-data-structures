## 🎯 Convención de Nombres de Carpetas
Para mantener los problemas ordenados y fáciles de buscar, recomendamos la siguiente convención:

```text

├── marco/
│   └── 0001_two_sum/
│       ├── solution.cpp
│       └── README.md
└── enrique/
    └── 0001_two_sum/
        ├── solution.cpp
        └── README.md
```

## 📝 Estructura Sugerida por Problema

2. Dificultad (*Easy*, *Medium*, *Hard*).
3. Enfoque o técnica (*Two Pointers*, *Hash Map*, *DP*, etc.).
4. Complejidad temporal y espacial (Big $O$).
