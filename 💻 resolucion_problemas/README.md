# 💻 Resolución de Problemas

Campo de entrenamiento y práctica continua de lógica, algoritmia y estructuras de datos.

---

## 🏛️ Arquitectura de la Carpeta
Para mantener el código organizado y permitir que tanto **Marco** como **Enrique** practiquen libremente sin generar conflictos en Git ni sobreescribir soluciones, esta carpeta se organiza por plataforma y luego por autor:

```text
resolucion_problemas/
├── Exercism/
│   ├── enrique/   # Soluciones y práctica de Enrique
│   └── marco/     # Soluciones y práctica de Marco
└── LeetCode/
    ├── enrique/   # Soluciones y práctica de Enrique
    └── marco/     # Soluciones y práctica de Marco
```

---

## 🛠️ Reglas de Convivencia y Práctica
1. **Aislamiento en Práctica:** Cada desarrollador trabaja exclusivamente dentro de su propia carpeta personal (`/marco/` o `/enrique/`).
2. **Comparar Enfoques:** Una vez resuelto un problema por ambos, se fomenta comparar la complejidad de tiempo/espacio y las decisiones de diseño.
3. **Commits Claros:** Usar Conventional Commits (`FEAT(leetcode): ...`, `FEAT(exercism): ...`) en español.
