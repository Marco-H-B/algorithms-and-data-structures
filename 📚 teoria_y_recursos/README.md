# 📚 Teoría y Recursos

Esta carpeta está dedicada a la base teórica de **Algoritmos y Estructuras de Datos (CC232)** y recursos de apoyo para el aprendizaje y preparación técnica.

---

## 🎯 Propósito
Centralizar apuntes, resúmenes matemáticos, diagramas y enlaces de referencia para entender a fondo el funcionamiento de cada concepto antes de codear.

---

## 🗂️ Contenido Sugerido
- **Apuntes y Resúmenes:** Conceptos clave de complejidad asintótica (Big $O$, $\Omega$, $\Theta$), análisis de recurrencias (Teorema Maestro) y demostraciones.
- **Cheat Sheets:** Resúmenes rápidos de complejidades temporales y espaciales de estructuras y algoritmos comunes.
- **Enlaces y Herramientas Visuales:**
  - [VisuAlgo](https://visualgo.net/) - Visualización interactiva de estructuras y algoritmos.
  - [CSVisTool](https://csvistool.com/) - Herramienta interactiva de estructuras de datos.
  - [USFCA Data Structure Visualizations](https://www.cs.usfca.edu/~galles/visualization/) - Simulador paso a paso.
